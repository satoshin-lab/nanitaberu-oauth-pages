このアプリについて

NaniTaberu YouTube Analyticsは、YouTubeチャンネル「ナニ食べる？」の運営者が、自分のチャンネルの動画・視聴・収益データを取得し、Googleスプレッドシートに保存して分析するための個人利用ツールです。

一般向けのユーザー登録やサービス提供は行いません。このページはアプリの目的とデータの取り扱いをご案内するものです。

Google・YouTubeへのアクセス目的

YouTube Data API v3とYouTube Analytics APIを利用し、許可されたチャンネルの情報、動画情報、視聴に関する統計、収益に関するデータを取得します。Google OAuthによる認可は、チャンネル運営者のデータへアクセスするために使用します。

取得処理はGoogle Apps Scriptで実行し、取得したデータを運営者が管理するGoogleスプレッドシートで分析します。

データの取り扱い

取得データはチャンネル運営の分析に使用し、第三者への販売や広告目的の利用は行いません。保存・共有・削除とアクセス権の解除については、プライバシーポリシーをご確認ください。
