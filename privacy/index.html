NANITABERU YOUTUBE ANALYTICS

プライバシーポリシー

作成日：2026年10月17日

本ポリシーは、YouTubeチャンネル「ナニ食べる？」の運営者（以下「運営者」）が個人利用するNaniTaberu YouTube Analytics（以下「本アプリ」）に適用します。

1. 使用するサービスと取得情報

本アプリはYouTube API Services（YouTube Data API v3およびYouTube Analytics API）を使用します。Google OAuthにより運営者が許可した範囲で、チャンネル情報、動画情報、視聴に関する統計、収益に関するデータを取得します。

Googleアカウントのパスワードを本アプリが取得・保存することはありません。APIへのアクセスにはGoogleが発行する認証用トークンを使用します。

2. 利用目的

取得データは、運営者自身のチャンネルの実績把握、動画の比較、コンテンツの改善、収益状況の確認に使用します。広告配信や第三者へのデータ販売には使用しません。

3. 保存先と管理

取得した分析データは、運営者が管理するGoogleスプレッドシートに保存します。処理はGoogle Apps Scriptで実行します。認証用トークンは分析データと分けて管理し、公開Webページや公開リポジトリに掲載しません。

動画情報は自動取得の実行時に更新します。視聴・収益などの日次データは直近14日分を再取得し、それより前のデータは日付を付けた履歴として、チャンネルの分析に必要な期間保存します。認証用トークンはApps Scriptのユーザープロパティに保存します。保存期間に応じた自動削除は行わず、運営者が保存データを管理・削除します。

4. 第三者への提供

取得データを第三者に販売・提供しません。本アプリの処理と保存にはGoogleのサービスを利用します。法令に基づく開示が必要な場合を除き、運営者の分析目的を超えてデータを共有しません。

5. アクセス権の解除

Googleアカウントのアクセス権管理画面から、本アプリへの許可をいつでも取り消すことができます。アクセス権の解除と、すでに保存したデータの削除は別の操作です。

6. 保存データの削除

運営者は、保存先のGoogleスプレッドシートとApps Scriptを管理します。利用を終了する場合は自動取得トリガーを停止し、保存データと認証用トークンを削除します。削除を希望する場合は、下記の問い合わせ先へご連絡ください。運営者が自動取得を停止し、対象のスプレッドシート内の取得データとApps Scriptに保存した認証用トークンを手動で削除します。削除依頼またはアクセス権の取り消しがあった場合は、できるだけ速やかに、遅くとも7日以内に対応します。本アプリ内の保存データを削除しても、YouTube上の動画やデータは削除されません。

7. 公開ページについて

説明ページと本ポリシーページには、広告・アクセス解析用のスクリプトを設置していません。公開ページの配信に伴うアクセス情報は、ホスティング事業者の方針に従って処理される場合があります。

8. 関連する規約とポリシー

GoogleプライバシーポリシーとYouTube利用規約もご確認ください。本アプリによるGoogle APIから受け取った情報の利用および他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。
